📱 Comment connecter votre ESP32 CYD en Wi-Fi :

  1. Ouvrez le code C++ dans firmware/src/main.cpp.
  2. Décommentez #define ENABLE_WIFI et entrez le nom et le mot de passe de votre box Wi-Fi.
  3. Renseignez l'IP du PC ci-dessus : const char* WS_SERVER_HOST = "192.168.10.136";
  4. Téléversez le firmware : votre CYD se connecte sans fil instantanément ! 🚀
